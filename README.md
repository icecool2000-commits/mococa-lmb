# Biribol Mococa na Liga

App da equipe de biribol de Mococa na Liga Metropolitana de Biribol. Ele reúne:

- a história de cada etapa;
- a lista de confirmação da próxima etapa;
- o ranking de participação dos atletas;
- as estatísticas da equipe e dos confrontos contra cada adversário.

Endereço: https://icecool2000-commits.github.io/mococa-lmb/
